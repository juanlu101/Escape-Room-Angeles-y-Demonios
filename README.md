# Ángeles y Demonios

Escape room para 4.º de ESO. Un contenedor de antimateria ha desaparecido del CERN y emite una señal desde Roma. Los equipos siguen el Camino de la Iluminación: cada prueba revela la coordenada del siguiente altar, que hay que localizar en el mapa e identificar antes de entrar. 
Autor: Juan Luis Torralbo Muñoz.
